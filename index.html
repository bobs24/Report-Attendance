How it works

  • The database is the truth. If a person + date is already in the database, Check shows the database version (☁) and ignores the file for that day.
  • Days not in the database come from the file. Fix them, then Save to database.
  • Editing a ☁ day (in Check or Dashboard) changes the database immediately.
  • On the Dashboard, Work day counts days that have an in and an out. A second in/out that runs into the next day (or starts the day before) counts as one more work day for that other date — but each calendar date is counted only once.
  • Working hours = total time on the clock, overtime included. Overtime = the part after the schedule end, from minute 0. Early never counts.
  • Day off: every worked minute is overtime. Overtime allowed not ticked: overtime 0.
