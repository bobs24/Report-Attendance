How the hours are counted

  • A tap is always shown on the date it happened. ?? means the machine has no tap.
  • Two taps within 10 minutes count as one press.
  • Working hours = the total time on the clock, overtime included.
  • Overtime = the part after the end of the schedule worked, from the first minute. Arriving early never counts.
  • On a Day off / holiday, every worked minute is overtime.
  • Overtime allowed not ticked = overtime 0; working hours stay the same.
  • Days with ?? count 0 hours until you fix them, and are not saved to the database.

Database — Supabase, set in the code (search for SUPABASE_URL in index.html). Only clean records are saved.
